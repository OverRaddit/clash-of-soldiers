# 가챠 — 구현 규칙서

원문 룰(참고: 호러레이스, 보난자)을 웹 게임으로 옮기며 확정한 규칙과, 원문이 명시하지 않아 **해석으로 정한 부분**을 적는다.
엔진은 `backend/src/game-room/gacha/engine.ts`, 화면은 `frontend/src/components/GachaGame.tsx`.
해석이 바뀌면 이 문서와 엔진의 해당 함수만 고치면 된다.

## 구성물

원문은 4인 기준이다. 인원이 달라도 구성은 같고 돼지 보드처럼 플레이어 수에 따라 늘어나는 것은 코인뿐이다.

| 구성 | 값 | 비고 |
| --- | --- | --- |
| 캐릭터 카드 | A 토끼 · B 고양이 · C 곰 · D 펭귄, 각 13장 (총 52장) | `CARDS_PER_KIND` |
| 코인 | 1인당 12개 | `COINS_PER_PLAYER`. 원문 48장 ÷ 4인 |
| 라운드 | 인원 × 3 (각자 사장님 3회) | `ROUNDS_PER_PLAYER` |
| 사장님이 가져오는 장수 | 4장 (덱이 그보다 적으면 남은 전부) | `DRAW_COUNT` |
| 인원 | 3~6명, 기본 4명 | `MIN_PLAYERS`, `MAX_PLAYERS`. 교환에 손님 2명이 필요하므로 최소 3명 (해석) |

캐릭터 이름(토끼·고양이·곰·펭귄)은 화면 구분용이며 규칙에는 영향이 없다.

## 세팅

1. 각자 캐릭터 카드를 종류별 1장씩(4장) 받고, 그중 **최애**(3점)와 **차애**(2점)를 고른다. 순서가 있으므로 첫 선택이 최애다.
2. 고른 2장은 최애-차애 보드에 올라간 것으로 보고 **점수용 카드로 세지 않는다.** (해석: 보드 카드는 표식이다.)
3. 고르지 않은 2장은 모아서 나머지 카드(52 − 4×인원)와 함께 섞어 덱을 만든다.
4. 1라운드 사장님(선플레이어)은 **무작위**로 정한다. (해석) 이후 입장 순서대로 돌아간다.

## 라운드 진행

### 1. 진열 (사장님)

- 사장님이 덱 위에서 4장을 가져와 확인하고, 그중 1~4장을 골라 뒷면으로 가챠기계에 넣는다.
- **넣지 않은 카드는 확인하지 않은 채 덱 맨 아래로 돌아간다.** (해석: 원문이 사장님이 남긴 카드의 행방을 적지 않았다. 사장님이 가질 수 있게 하면 가장 좋은 카드를 매번 챙기게 되어 가챠가 성립하지 않는다.)
- **가챠기계 안 카드 순서는 섞인다.** 사장님도 어느 칸에 무엇이 있는지 모른다. (해석: 가챠는 무작위여야 하고, 사장님이 위치를 알면 손님에게 신호를 줄 수 있다.)

### 2. 뽑기 (손님)

- 사장님 다음 사람부터 시계 방향으로, 차례마다 코인 1개를 **사장님에게** 내고 기계의 칸 하나를 골라 뽑는다. 뽑은 카드는 즉시 **모두에게 공개**되어 그 사람 앞에 놓인다.
- 한 차례에 한 번만 뽑는다. 모두 한 번씩 돌고도 카드가 남아 있으면 다시 돌며 더 뽑을 수 있다.
- 차례에 뽑지 않고 **"뽑기 마치기"** 를 누르면 이번 라운드에는 다시 차례가 오지 않는다. (해석: 원문의 "가챠 돌리기를 마치면"을 라운드 단위로 본다.)
- 코인이 없는 손님은 자동으로 건너뛴다. 사장님은 뽑지 않는다. (해석: 사장님은 파는 쪽이다.)
- 기계가 비거나 모든 손님이 마치면 뽑기가 끝난다. 남은 카드는 **확인하지 않고 덱 맨 아래**로 간다.

### 3. 손으로 가져오기

뽑은 카드는 모두 각자 손으로 들어가 이후 **비공개**가 된다. 화면 옆의 "공개된 뽑기" 표는 라운드마다 누가 어떤 캐릭터를 뽑았는지 누적해서 보여 준다 (추리용). 교환으로 넘어간 카드는 표에 반영되지 않는다.

### 4. 교환 (손님끼리)

- 사장님을 뺀 손님끼리만, **카드 또는 코인을 1:1**로 바꾼다. 코인끼리 교환은 의미가 없어 막았다.
- 웹에서는 **제안 → 수락/거절** 방식이다. 한 사람은 동시에 제안 하나만 걸 수 있고, 취소할 수 있다. 제안 내용(무엇과 무엇)은 모두에게 보인다. (해석: 테이블에서 교환은 공개적으로 이뤄진다.)
- 수락 시점에 양쪽이 실제로 그 물건을 갖고 있어야 성립한다. 카드는 종류만 지정하며 그 종류 중 한 장이 넘어간다.
- 각자 **"교환 마치기"** 를 누르면 자기가 낸 제안은 거둬지고, 받은 제안은 여전히 수락·거절할 수 있다. 손님이 모두 마치면 라운드가 끝난다.

### 5. 다음 라운드

다음 사람이 사장님이 되어 반복한다. 덱이 완전히 비어 가져올 카드가 없으면 그 라운드는 진열·뽑기 없이 교환만 진행한다. (해석: 극단적 상황 대비.)

## 종료와 점수

- 인원 × 3라운드가 끝나면 최애·차애를 공개한다.
- 점수 = 최애 카드 × 3 + 차애 카드 × 2 + 코인 × 1. **네 캐릭터를 모두 2장 이상** 모았으면 +5.
- 가장 높은 점수가 승리. 동점이면 **사장님을 먼저 한 사람**이 이기므로 공동 순위는 없다.

## 해석이 필요했던 지점 요약

| 지점 | 선택 | 바꾸려면 |
| --- | --- | --- |
| 인원 | 3~6명 (교환에 손님 2명 필요) | `MIN_PLAYERS`, `MAX_PLAYERS` |
| 코인·라운드 | 1인당 12개, 인원 × 3라운드 | `COINS_PER_PLAYER`, `ROUNDS_PER_PLAYER` |
| 선플레이어 | 무작위 | `initializeGachaGame` |
| 최애·차애 보드 카드 | 점수에 세지 않음 | `choose`, `scoreOf` |
| 사장님이 넣지 않은 카드 | 덱 맨 아래로 | `stock` |
| 기계 속 카드 순서 | 섞음 (사장님도 모름) | `stock` |
| 사장님 뽑기 | 불가 | `nextPuller` |
| 뽑기 패스 | 그 라운드 끝까지 차례 없음 | `pass`, `nextPuller` |
| 교환 방식 | 공개 제안 → 수락, 1인 1제안 | `offer`, `accept` |
| 코인↔코인 교환 | 불가 | `offer` |
| 교환 종료 | 손님 전원이 마치기 | `done` |
| 덱 소진 | 교환만 진행 | `beginRound` |
