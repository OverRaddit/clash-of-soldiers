# 월드 배팅 컵: 뒷세계의 승부조작단 — 구현 규칙서

원문 룰북을 웹 게임으로 옮기며 확정한 규칙과, 원문이 명시하지 않아 **해석으로 정한 부분**을 적는다.
엔진은 `backend/src/game-room/world-betting-cup/engine.ts`, 화면은 `frontend/src/components/WbcGame.tsx`.
해석이 바뀌면 이 문서와 엔진의 해당 함수(`settleMatch`, `validateBet`, `finishGame`)만 고치면 된다.

## 구성물

| 항목 | 내용 |
| --- | --- |
| 국가 카드 16장 | 시드 5(+2), 강팀 6(+1), 약팀 5(+0). 실제 국가 이름은 분위기용이며 규칙상 의미는 등급뿐이다. |
| 스코어 카드 25장 | 0·1·6·7 각 2장, 2·3·4·5 각 4장, [무조건 무승부] 1장 |
| 플레이어 토큰 | 일반(패배 배팅) 7개, 승부 조작 2개, 승리 배팅 3개 |
| 공용 더미(은행) | 30개에서 시작. 부족해도 지급은 계속되며 화면에 잔량만 표시한다. |

## 준비

1. 시드 4장, 강팀 3장 + 약팀 1장을 무작위로 뽑아 8강 대진을 만든다. **시드는 1·3·5·7번 칸, 나머지는 2·4·6·8번 칸**에 놓아 8강 네 경기가 모두 시드 대 비시드가 된다. (해석: 원문은 "시드 4칸"의 위치를 말하지 않는다.)
2. 모든 플레이어가 일반 토큰 1개로 우승팀 선배팅을 한다. **이 토큰은 돌려받지 않는다**(8강 탈락 보상 "없음"이 손실을 뜻한다고 봄). 모두 마치면 1경기가 시작된다.

## 경기 진행 (8강 4 → 4강 2 → 결승 1)

### 0단계 준비
- 더미를 섞어 비공개 6장(홈 점수 2, 원정 점수 2, 홈 승부차기 1, 원정 승부차기 1)과 공개 5장을 깐다. 원문의 "점수 칸 4장, 승부차기 칸 각각 2장씩"은 합계 6장이므로 **승부차기 칸은 팀당 1장**으로 해석했다.
- 남은 더미는 14장.

### 1단계 정보 탐색
- 시작 플레이어는 경기마다 한 칸씩 시계 방향으로 넘어간다(1경기 1번 자리, 2경기 2번 자리…). (해석: 원문 미명시)
- 시계 방향으로 한 바퀴 → 더미에서 2장 추가 공개 → 역순으로 한 바퀴(스네이크).
- **A. 내부 정보 수집**: 비공개 6장 중 2장을 골라 본인만 확인. 어느 칸을 봤는지는 모두에게 보이고(실물 테이블과 동일), 값은 본인 화면의 메모에만 남는다.
- **B. 승부 조작**: 비공개 1장을 지정 + 더미 위 2장 → 셋 중 1장을 그 칸에 되돌리고 나머지 2장은 더미 맨 아래로. 어느 칸을 골랐는지는 공개, 교체 여부는 비공개. 남긴 카드 값은 본인 메모에 기록된다.
- 다른 플레이어가 먼저 본 카드를 뒤에 누군가 조작하면, 먼저 본 사람의 메모는 그대로 남는다(실제로도 모른다). 칸 위의 "조작 ○○" 표시로 눈치챌 수 있다.

### 2단계 배팅
- 시작 플레이어부터 시계 방향으로 한 번씩, **질 것 같은 나라**에 배팅하거나 다이.
- 1~3개(결승 1~4개). 일반·조작·승리 토큰 합계를 "개수"로 센다.
- **맞추기 규칙**: 앞사람 중 최고 배팅 개수와 같은 수를 내야 한다. 올리는 것은 없다(해석: "동일한 수만큼"). 일반 토큰이 최고 배팅보다 적으면 **가진 일반 토큰을 전부 거는 올인**이 허용되며, 이때 특수 토큰을 더해 최고 배팅 이하까지 낼 수 있다.
- 배팅 중에는 누가 어느 나라에 몇 개를 냈는지만 보이고 토큰 종류는 공개 전까지 숨긴다(본인 것은 보인다).
- 승리 배팅 토큰을 일반/조작 토큰과 섞어 내는 것은 막지 않는다. 공개 시 규칙대로 **전부 몰수**된다(일반 토큰은 공용 더미로, 특수 토큰은 소멸). 화면에서 경고를 띄운다.

### 3단계 정산
1. 토큰 공개, 몰수 판정. 몰수된 배팅은 참여하지 않은 것으로 보고 **조작 효과도 내지 않는다**.
2. 점수 공개. 점수 칸 4장 중 [무조건 무승부]가 있으면 곧바로 승부차기.
   `득점 = max(0, 높은 카드 + 팀 보너스 − 낮은 카드 − 그 나라 위의 조작 토큰 수)`
3. 동점이면 승부차기. 승부차기 카드 1장씩 비교(6→1, 7→2). 동점이거나 [무조건 무승부]가 있으면 더미 위 2장을 홈·원정 순으로 겹쳐 놓고 반복. 더미가 2장 미만이면 승부차기에 쓴 카드를 모두 섞어 더미로 되돌린다. 승부차기에는 **팀 보너스와 조작 토큰을 적용하지 않는다**(해석: 원문은 조작 토큰만 언급).
4. **배당**: 유효한 배팅 토큰 전부(양쪽 나라 합산)가 판돈. 패배한 나라에 건 플레이어(승리 토큰은 반대편에 건 것으로 환산)가 **인원수로 균등하게 나누고 올림**, 부족분은 공용 더미에서 보충. 적중자가 없으면 판돈은 공용 더미로.
   - 특수 토큰은 공용 더미의 일반 토큰 1개로 바꿔 판돈에 넣고 주인에게 **돌려준다**. 따라서 특수 토큰은 경기마다 다시 쓸 수 있고, 배팅에 져도 특수 토큰만큼은 잃지 않는다(원문의 "일반 토큰 1개로 바꾸어"를 문자 그대로 따름).
5. **보너스**(적중자 각자에게, 공용 더미에서): 4강 +1, 결승 +2. **역배 성공** +2: 적중자가 혼자이고 반대편에 건 사람이 2명 이상이거나, 이긴 나라의 팀 보너스가 진 나라보다 낮을 때. 두 조건을 동시에 만족해도 +2 한 번만.
6. 승자는 대진표 다음 칸으로. 모든 스코어 카드를 다시 섞어 다음 경기 준비. 아무나 "다음 경기로"를 누르면 진행된다.

## 종료

결승 정산 직후 선배팅 보상(우승 5, 준우승 2, 4강 1, 8강 탈락 0)을 지급하고 일반 토큰이 가장 많은 플레이어가 승리한다. 동점은 공동 순위. 특수 토큰은 점수에 넣지 않는다.

## 인원

원문에 없어 **2~6명**으로 열었다(토큰 30개의 공용 더미와 8강 대진 규모를 감안). 기본값 4명.

| 지점 | 선택 | 바꾸려면 |
| --- | --- | --- |
| 승부차기 카드 수 | 팀당 1장 | `startMatch` 의 `hidden` 분배, `runShootout` |
| 선배팅 토큰 반환 | 반환 없음 | `applyWbcAction` 의 `prebet`, `finishGame` |
| 맞추기 규칙에서 올리기 | 불가, 올인만 예외 | `validateBet`, `betConstraints` |
| 배당 분배 | 인원수 균등(올림) | `settleMatch` 4단계 |
| 특수 토큰 처리 | 은행이 1개씩 대신 넣고 주인에게 반환 | `settleMatch` 1단계 |
| 적중자 없을 때 판돈 | 공용 더미로 | `settleMatch` 4단계 |
| 몰수된 배팅의 조작 효과 | 없음, 특수 토큰 소멸 | `settleMatch` 1단계 |
| 역배 중복 | +2 한 번 | `settleMatch` 5단계 |
| 승부차기 팀 보너스 | 미적용 | `runShootout` |
| 시작 플레이어 | 경기마다 한 칸씩 이동 | `startMatch` |
| 시드 배치 | 홀수 칸 | `initializeWbcGame` |
