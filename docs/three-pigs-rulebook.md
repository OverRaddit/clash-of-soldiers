# 아기 돼지 삼형제의 아파트 짓기 — 구현 규칙서

원문 룰(드렉사우 참고작)을 웹 게임으로 옮기며 확정한 규칙과, 원문이 명시하지 않아 **해석으로 정한 부분**을 적는다.
엔진은 `backend/src/game-room/three-pigs/engine.ts`, 화면은 `frontend/src/components/PigsGame.tsx`.
해석이 바뀌면 이 문서와 엔진의 해당 함수(`placementError`, `apartmentScore`, `finishGame`, `CARD_COUNTS`)만 고치면 된다.

## 구성물

원문은 카드 장수를 모두 N으로 적어 두었다. 2~5인에서 한 사람이 세 채를 완공하기까지(최소 터 3·철근 3·콘크리트 3·정원 3 = 12장) 적당히 걸리도록 정했다.

| 카드 | 장수 | 역할 |
| --- | --- | --- |
| 터 | 16 | 아파트의 평수. 한 아파트에 여러 장 가능. 콘크리트가 올라간 뒤에는 추가 불가. 다이너마이트 대상 아님. |
| 철근 | 26 | 새 층의 뼈대. 콘크리트보다 먼저. |
| 콘크리트 | 26 | 철근 위에 올려 층을 완성. |
| 다이너마이트 | 14 | 상대 아파트의 맨 위층 폭파. 즉시 버림. |
| 방범 마감재 | 8 | 그 층 이하는 다이너마이트 무효. 옮길 수 없음. |
| 정원 | 12 | 아파트 완공. 이후 공격·증축 불가. |
| 돼지 | 인원 × 3 | 플레이어당 아파트 3채의 바닥. |

총 102장. 시작 손패 5장.

## 준비

1. 각자 돼지 카드 3장(= 1·2·3호 아파트)을 받는다.
2. 나머지 카드를 섞어 5장씩 나눠 가진다.
3. 선플레이어는 "가장 높은 층에 사는 사람"을 웹에서 알 수 없으므로 **무작위**로 정한다. (해석)

## 턴 진행

1. 턴이 시작되면 **자동으로** 덱에서 1장을 뽑는다. 덱이 비면 버린 더미를 섞어 새 덱을 만든다.
2. 손패 1장을 **사용**하거나 **버린다**. 쓸 수 있는 카드가 있어도 버리는 것을 허용한다. (해석: 원문은 "사용할 카드가 없다면" 버린다고 적었지만, 쓸모없는 카드를 강제로 쓰게 하면 게임이 망가지므로 자유 선택으로 둔다.)
3. 시계 방향으로 다음 사람에게 넘어간다. 손패가 비어 있으면 차례를 건너뛴다. 덱·버린 더미·모든 손패가 비면 점수로 끝낸다.

## 아파트 구조와 카드 규칙

아파트 한 채는 **터 N장 + 층 목록 + 방범 위치 + 완공 여부**로 표현한다. 한 층은 철근 1장 + 콘크리트 1장.

| 카드 | 낼 수 있는 조건 (내 아파트, 미완공) |
| --- | --- |
| 터 | 콘크리트가 올라간 층이 하나도 없을 때. 철근만 있으면 가능. |
| 철근 | 터가 1장 이상이고, 맨 위층이 완성(콘크리트 있음)되어 있거나 층이 없을 때. |
| 콘크리트 | 맨 위층이 철근만 있을 때. |
| 방범 마감재 | 현재 보호 층보다 높은 **완성 층**이 있을 때. 자동으로 가장 높은 완성 층에 설치한다. (해석: 더 낮은 층에 놓는 것은 항상 손해라 선택지를 없앴다. 한 아파트에 여러 번 설치해 보호 층을 올릴 수 있다.) |
| 정원 | 터 1장 이상, 층 1개 이상, 맨 위층이 완성되어 있을 때. (해석: 철근만 있는 층 위에는 정원을 올릴 수 없다.) |
| 다이너마이트 | **상대** 아파트, 미완공, 층이 1개 이상, 맨 위층이 방범 보호 층보다 위일 때. |

### 다이너마이트 효과 (해석)

"최상위 1개층 폭파"를 **맨 위층 통째로**로 해석한다. 맨 위층이 철근만 있으면 철근 1장, 완성 층이면 철근 + 콘크리트 2장이 사라진다. 사라진 카드와 다이너마이트는 버린 더미로 가서 덱 재구성 때 돌아온다. 방범 마감재는 자기 층 아래에만 효과가 있으므로, 방범 위로 올린 층은 폭파될 수 있다.

## 종료와 점수

- 누군가 정원으로 **세 번째 아파트를 완공하는 즉시** 종료한다.
- 아파트마다 `터 × 완성 층수`. 철근만 있는 층은 세지 않는다. 미완공 아파트도 같은 식으로 점수를 받는다. (해석)
- 층 보너스: 완성 층 3~4개 +1, 5개 이상 +2. **중복 없이 큰 쪽 하나**만 더한다. (해석: "5층 이상은 2점이 추가"를 3층 보너스를 대체하는 것으로 봄. 누적 +3으로 바꾸려면 `apartmentScore` 한 줄.)
- 가장 높은 점수가 승리. 동점이면 게임을 끝낸 사람이 앞서고, 그 외 동점은 공동 순위. (해석)

## 인원

원문의 돼지 카드가 "인원수 × 3"이라 인원 제한이 없다. 덱 102장과 턴 속도를 감안해 **2~5명**, 기본 4명으로 열었다.

## 해석이 필요했던 지점 요약

| 지점 | 선택 | 바꾸려면 |
| --- | --- | --- |
| 카드 장수 N | 터 16 / 철근 26 / 콘크리트 26 / 다이너마이트 14 / 방범 8 / 정원 12, 손패 5 | `CARD_COUNTS`, `HAND_SIZE` |
| 선플레이어 | 무작위 | `initializePigsGame` |
| 버리기 | 언제나 허용 | `applyPigsAction` 의 `discard` |
| 다이너마이트 범위 | 맨 위층 통째로(철근만 있어도 그 층) | `applyPigsAction` 의 `dynamite` |
| 방범 설치 위치 | 가장 높은 완성 층, 여러 번 가능 | `placementError`, `applyPigsAction` 의 `guard` |
| 정원 조건 | 터·층 있음 + 맨 위층 완성 | `placementError` |
| 층 보너스 | 3층 +1 또는 5층 +2 (큰 쪽만) | `apartmentScore` |
| 미완공 아파트 점수 | 완공과 동일하게 계산 | `apartmentScore` |
| 동점 | 끝낸 사람 우선, 그 외 공동 | `finishGame` |
| 인원 | 2~5명 | `MIN_PLAYERS`, `MAX_PLAYERS` |
