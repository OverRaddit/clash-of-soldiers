# 봄버스터즈 음성 미션의 기계적 규칙

2026-09-20 공식 Pegasus 영문 MP3 5개를 내려받아 로컬 음성인식으로 분석했다. 전체 구간은 small.en 모델을 음성 감지 사용/미사용 두 방식으로 대조했고, 숫자·특수 승패·후반 구간은 medium.en으로 다시 확인했다. 아래는 대본 번역이 아닌 진행 규칙 요약이다. 발화 시각은 음원 시작 기준이며 신호음 경계와 약 1–3초 차이가 날 수 있다. 무음·음악의 자동 전사 환각은 제외했다.

공통으로 준비와 초기 정보토큰 배치를 마친 뒤 시작한다. 정지 신호부터 재개 신호까지 절단을 멈추고 지시를 듣는다. 설명 시간은 명시된 작업시간에서 제외한다. 웹 구현은 한국어 지시 확인 중 서버 타이머를 멈추고 실제 작업 구간만 계산한다. 원본 녹음과 한국어 안내를 동시에 작동시키는 방식은 사용하지 않는다.

## 19 — 카운트다운 단축

처음에는 15분을 준다고 알린다. 12분 남음 안내 뒤, 약 7:02에 10분 남음을 알렸다가 약 7:19에 남은 시간을 갑자기 5분으로 줄인다. 이후 2분·30초 경고와 최종 카운트다운이 나온다. **MP3 끝이 제한시간이 아니다.** 약 12:48의 최종 카운트다운 직후 폭발하고 뒤에는 추가 조롱 음성이 이어진다. 녹음에서 추가 전선·장비 규칙은 발견되지 않았다. 설명 시간을 제외한 디지털 작업 구간은 3분→2분→3분→1분30초→30초로 표현할 수 있다.

## 30 — 속도 미션

[공식 음원](https://cdn.pegasus.de/public/media/44/46/01/1759224867/BB-Final_Mission-30.mp3?ts=1759240277).

숫자카드를 공개할 때마다 그 숫자의 전선 2개 이상이 잘려 있어야 한다. 이미 잘린 전선도 인정하고 다른 값을 먼저 잘라도 된다. 다음 공개 때 이전 카드는 버린다.

| 점검 발화 시각 | 앞선 작업시간 | 목표 결과 |
| --- | --- | --- |
| 약 2:34 | 20초 | 실패: 기폭기 +1 |
| 약 3:18 | 20초 | 성공·실패 모두 보상/벌점 없음 |
| 약 3:54 | 20초 | 실패: 공개 장비 중 가장 작은 번호 제거 |
| 약 4:35 | 20초 | 성공: 전원이 자기 노랑 개수 공개 |
| 약 5:14 | 15초 | 실패: 현재 플레이어는 이후 말 대신 몸짓만 가능, 위반마다 +1 |
| 약 5:52 | 15초 | 성공: 현재 플레이어가 추가 숫자카드를 뽑아 해당 값 보유 여부 공개 |
| 약 6:29 | 15초 | 성공: 그 값의 남은 두 전선도 즉시 절단 |

그 뒤 숫자카드 3장을 공개하고 **2분** 동안 그 세 값만 자른다. 해당 값이 없는 차례는 패스한다. 세 값의 전선 네 개씩을 모두 잘랐으면 **나머지 전선과 무관하게 즉시 승리**한다. 실패했다면 현재 플레이어가 남은 노랑 전부를 한 번에 절단해야 한다. 틀리면 즉시 패배, 맞으면 목표카드를 버리고 **2분** 동안 나머지 전선을 처리한다. 마지막 카운트다운은 약 11:42–11:48이다. 보상용 추가 숫자카드의 이후 처리와 노랑이 이미 0개인 구제 분기는 녹음에 별도 설명이 없다.

## 42 — 서커스의 방해

[공식 음원](https://cdn.pegasus.de/public/media/96/d0/2a/1759224868/BB-Final_Mission-42.mp3?ts=1759240277).

**시간제한이 없다.** 녹음 종료 후에도 기본 승리 조건까지 계속한다.

| 발화 시각(대략) | 사건 |
| --- | --- |
| 2:14, 7:15, 11:24 | 현재 마술사 외에는 보지 않는다. 마술사가 이미 잘린 같은 값 한 쌍을 원래 받침대로 복구한 뒤 다음 사람 차례로 진행한다. |
| 3:30 | 받침대는 두고 전원이 왼쪽 자리로 이동. 기존 행동자가 새 자리에서 차례를 재개한다. |
| 4:20, 8:37 | 현재 플레이어의 서로 다른 값인 절단 전선 2개의 위치를 바꾼다. |
| 5:00, 13:40 | 받침대는 두고 전원이 오른쪽 자리로 이동한다. |
| 5:40 | 현재 플레이어의 절단 전선을 모두 받침대에서 제거한다. 미절단 전선은 유지한다. |
| 6:27 | 이후 전선을 자를 때마다 완료 구호를 말한다. |
| 9:21 | 놓인 것과 남은 것 모두 포함해 완료토큰을 제거한다. |
| 10:02, 12:10, 12:57, 14:40 | 현재 플레이어부터 시계방향으로 트램펄린 구호를 차례대로 말한다. |
| 약 10:42 | 직전 절단자가 완료 구호를 빠뜨렸으면 기폭기 +1. |

온라인에서는 눈 감기를 비공개 선택 화면으로, 자리 이동을 받침대 소유자 이동으로, 구호를 버튼으로 표현한다. 실제 발화 대신 완료 구호 버튼의 상태를 점검한다. 칼 던지기로 상자에 치운 전선은 빈자리로 표시하되 내부 완료 계산에는 남기며, 이후 마술·저글링 대상으로 선택할 수 없다. 마술 복구값이 숫자별 자동 집계의 변화로 공개되지 않도록 첫 마술부터 집계판을 숨기고 이미 해금한 장비는 해금 상태를 유지한다.

## 54 — 산소와 침수

[공식 음원](https://cdn.pegasus.de/public/media/d4/e9/5f/1759224868/BB-Final_Mission-54.mp3?ts=1759240277).

순수 작업시간은 **10분**이다. 카드의 산소 비용·완료토큰 보충 규칙을 적용한다. 빨강 11개는 처음 손에 나눠주지 않는다.

- 빨강 추가 지시는 약 2:59, 5:54, 8:09, 10:02, 11:27, 12:01에 나온다. 현재 플레이어가 한 개를 비공개로 뽑아 정렬한다. 들어간 위치는 공개한다.
- 약 3:49, 8:44에는 현재 플레이어가 바로 다음 차례까지 연속으로 행동한다.
- 약 4:31, 7:28에는 현재 플레이어가 산소 1개를 받는다.
- 약 6:34, 10:42, 12:55에는 현재 플레이어가 동료 한 명과 산소를 주거나 받을 수 있다.
- 약 9:35에 4분, 12:29에 2분 남음 안내가 나온다.
- 약 13:44에는 마지막 숨을 참으며 끝내라는 신체 행동 지시가 나온다. 웹 버전에서는 이를 요구하지 않고 마지막 해체 구간 안내로 대체한다.

마지막은 숫자 카운트다운 없이 효과음으로 끝나므로 자동 음성인식으로 폭발의 정확한 표본 시각을 확정하지 않았다. 신호음을 파형 상관으로 검출했지만 녹음의 남은 시간 안내와 감지된 작업 구간 합에는 차이가 있다. 따라서 디지털 구현은 **600초 작업시간을 기준**으로 사건 순서를 유지해 간격을 정규화한다. 이는 원본 MP3와 초 단위로 동기화된 재생을 뜻하지 않는다.

## 66 — 벙커 진입

[공식 음원](https://cdn.pegasus.de/public/media/1a/1d/84/1759224868/BB-Final_Mission-66.mp3?ts=1759240277).

| 단계 | 순수 작업시간 | 통과 조건 |
| --- | --- | --- |
| 문 열기 | 80초 | 열쇠 칸에서 ACTION 제약에 맞는 절단 성공 |
| 경비 제압 | 75초 | 경비 칸에서 ACTION 절단 성공 |
| 지하 진입 | 60초 | 계단 도착 후 지하 지도로 이동 |
| 레이저 해제 | 90초 | 레버 칸에서 노랑 두 개 절단. 현재 행동자가 노랑을 갖지 않아도 시도 가능 |
| 제약 재배치 | 10초 | 방향 4장·ACTION 1장 배치를 선택적으로 변경 |
| 닥터 노프 체포 | 105초 | 닥터 칸에서 ACTION 절단 성공 |
| 폭탄 마무리 | 20초 | 남은 전선 처리 |

각 점검에서 앞선 목표를 못 이뤘으면 즉시 패배한다. 첫 네 단계는 조기 완료하면 현위치에서 절단·이동을 멈추고 다음 지시를 기다리라고 명시한다. 체포 단계의 조기 대기는 별도로 재진술되지 않는다. 지도 양면의 4열×3행 북쪽 기준 좌표, 벽·문·계단·함정·레이저는 카드 스캔과 두 사람이 독립 대조했다. 실제 지도 데이터는 `campaign-bunker.ts`에 있다.

디지털 진행에서는 체포 성공 뒤에도 다음 지시까지 대기한다. 이동 방향이나 실패 정보 토큰을 고르는 동안에는 작업시간이 계속 흐른다. 레이저의 두 대상이 모두 오답이면 한 전선을 선택해 정보 토큰을 놓는다. 이 선택은 [공식 FAQ](https://www.cocktailgames.com/nos-jeux/bomb-busters-faq/)로 확인했다.

## 디지털 진행에서 정한 세부 처리

30번의 보유 여부 공개에 쓴 추가 숫자카드는 다시 뽑히지 않게 제외한다. 구제 시점에 남은 노랑이 없다면 구제 성공으로 간주하고 마지막 2분을 진행한다. 이는 녹음에 별도 설명이 없는 두 경우에 대한 구현 선택이다. 설명·선택을 확인하는 시간에는 타이머를 멈추므로 원본 MP3 재생 시간과 서버 단계 시간이 일치하지 않는다. 숫자로 명시된 작업시간을 우선하며, 42번 사건 사이 간격과 54번 사건 배치는 녹음을 바탕으로 디지털 구간을 정했다.
