# 보드게임 플랫폼

## 반지 원정대 트릭테이킹 게임

1. `backend`에서 `npm install && npm run start:dev`, `frontend`에서 `npm install && npm start`를 실행합니다.
2. 로비에서 **반지 원정대** 방을 만들고 1~4명이 참가합니다. 1명은 네 손패를 조종하고, 2명은 공개 피라미드 패를 포함한 세 좌석을 사용합니다.
3. 방장이 1~18장 중 챕터를 선택합니다. 모든 참가자가 준비하면 캐릭터 선택, 준비 행동, 트릭 플레이를 진행합니다.
4. 캐릭터 목표와 사건·저주·선물 효과를 적용해 짧은 장은 한 라운드, 긴 장은 여러 라운드, 마지막 장은 두 그룹의 라운드로 완료합니다.

규칙과 챕터·카드별 출처는 [자료 조사 문서](docs/fellowship-trick-taking-sources.md)에, 기계 판독형 효과는 [카탈로그](backend/src/game-room/fellowship/catalog.ts)에 있습니다. 저작권이 있는 카드 그림과 룰북 PDF는 저장소에 포함하지 않았습니다.

## 월드 배팅 컵: 뒷세계의 승부조작단

1. 로비에서 **월드 배팅 컵** 방을 만들고 2~6명이 참가합니다.
2. 8강 대진이 무작위로 짜이면 모두 일반 토큰 1개로 우승팀을 선배팅합니다.
3. 경기마다 숨겨진 스코어 카드 6장을 몰래 보거나(내부 정보 수집) 바꿔치기(승부 조작)한 뒤, **질 것 같은 나라**에 토큰을 겁니다. 승부 조작 토큰은 그 나라의 점수를 깎고, 승리 배팅 토큰은 반대편에 건 것으로 칩니다.
4. 결승까지 7경기를 치르고 선배팅 보상까지 더해 토큰이 가장 많은 승부사가 이깁니다.

원문 룰북이 정하지 않은 부분의 해석은 [구현 규칙서](docs/world-betting-cup-rulebook.md)에 정리했고, 엔진은 [engine.ts](backend/src/game-room/world-betting-cup/engine.ts)에 있습니다.

## 모래 위의 밀약: 콜로세움의 큰손들

월드 배팅 컵의 카드 메커니즘을 이어받아 협잡 게임으로 다시 짠 판입니다.

1. 로비에서 **모래 위의 밀약** 방을 만들고 3~6명이 참가합니다.
2. 여덟 검투사의 대진이 짜이면 각자 남에게 숨긴 밀명 2장을 받습니다(3~4인은 3장 중 2장 선택).
3. 경기마다 숨겨진 전투 카드 6장을 염탐하거나 바꿔치기합니다. 첫 바퀴가 끝나면 모두 **이길 것 같은 문**에 내기 패를 비공개로 동시에 걸고, 역순으로 한 바퀴 더 행동한 뒤 결투합니다.
4. 7경기 뒤 내기 적중 1회당 1점에 달성한 밀명 점수(2~5점)를 더해 가장 높은 큰손이 이깁니다.

규칙과 테마 디자인은 [룰북](docs/colosseum-rulebook.md), 설계 배경은 [구상 초안](docs/world-betting-cup-v2-concept.md), 엔진은 [engine.ts](backend/src/game-room/colosseum/engine.ts)에 있습니다.

## 확보! (멀티피치 트릭테이킹)

1. 로비에서 **확보!** 방을 만들고 4명이 참가합니다. 입장 순서대로 1번(선등)부터 4번(후미)까지 로프로 묶입니다.
2. 매 트릭 전원이 카드를 한 장씩 냅니다. 카드 숫자가 바로 위 칸의 난이도 이상이면 한 칸 오르고, 트릭 승자는 텐션·장비 걸기·콜 회복 중 하나를 고릅니다.
3. 추락 카드는 벽에 붙어 있을 때만 낼 수 있고(바닥·확보점·정상에서는 금지), 그 트릭을 빌레이어가 이겨야 잡힙니다. 부상 3회, 선등자 그라운드 폴, 2딜 안에 정상 미도달이면 패배입니다.

규칙 전문은 [룰북 v0](docs/multipitch-rulebook-v0.md), 엔진은 [engine.ts](backend/src/game-room/multipitch/engine.ts)에 있습니다.

## 아기 돼지 삼형제의 아파트 짓기

1. 로비에서 **아기 돼지 삼형제** 방을 만들고 2~5명이 참가합니다.
2. 각자 돼지 카드 3장(아파트 3채)과 손패 5장을 받고, 턴마다 1장을 뽑아 1장을 사용하거나 버립니다.
3. **터 → 철근 → 콘크리트** 순서로 층을 올리고 정원으로 완공합니다. 다이너마이트는 상대 아파트의 맨 위층을 날리고, 방범 마감재는 그 아래층을 지킵니다.
4. 한 사람이 세 채를 모두 완공하면 종료. 아파트마다 터 × 완성 층(3층 이상 +1, 5층 이상 +2)을 더해 가장 높은 점수가 이깁니다.

카드 장수와 해석은 [구현 규칙서](docs/three-pigs-rulebook.md)에, 엔진은 [engine.ts](backend/src/game-room/three-pigs/engine.ts)에 있습니다.

## 가챠

1. 로비에서 **가챠** 방을 만들고 3~6명이 참가합니다.
2. 캐릭터 카드 A·B·C·D 중 **최애(3점)** 와 **차애(2점)** 를 몰래 정하고 코인 12개를 받습니다.
3. 라운드마다 사장님이 덱에서 4장을 가져와 1~4장을 가챠기계에 뒷면으로 진열합니다. 손님은 차례마다 코인 1개를 내고 한 장을 뽑으며, 기계가 빌 때까지 돌 수 있습니다. 뽑기가 끝나면 손님끼리 카드·코인을 1:1로 교환합니다.
4. 인원 × 3라운드 뒤 최애·차애·코인 점수에 네 캐릭터를 2장씩 모은 보너스 5점을 더해 가장 높은 사람이 이깁니다. 동점이면 사장님을 먼저 한 사람이 이깁니다.

원문이 정하지 않은 부분의 해석은 [구현 규칙서](docs/gacha-rulebook.md)에, 엔진은 [engine.ts](backend/src/game-room/gacha/engine.ts)에 있습니다.

## 파프리카 대축제

1. 로비에서 **파프리카 대축제** 방을 만들고 3~6명이 참가합니다.
2. 돌아가며 육각 농장(37칸)에 **씨앗**이나 **도둑** 토큰을 뒷면으로 놓습니다. 내 토큰 바로 옆에는 내 토큰을 놓을 수 없어요. 1인당 토큰은 3명 5개 · 4명 4개 · 5~6명 3개.
3. 모두 놓으면 공개: 다른 도둑과 붙은 도둑은 제거, 살아남은 도둑은 옆 씨앗의 파프리카를 털고, 남은 씨앗은 주인이 수확합니다. 같은 씨앗을 노린 도둑이 둘이면 먼저 놓인 쪽이 가져가요.
4. 2라운드 뒤 총합 25개 이상이면 모두 승리, 24개 이하면 1등 1명만(4개 이상) 승리, 1등이 동점이면 모두 패배입니다.

해석은 [구현 규칙서](docs/paprika-rulebook.md)에, 엔진은 [engine.ts](backend/src/game-room/paprika/engine.ts)에 있습니다.

## 동물들의 숨바꼭질

1. 로비에서 **동물들의 숨바꼭질** 방을 만들고 3~5명이 참가합니다. 라운드 수는 참가 인원과 같습니다.
2. 카드 10장(동물 9 + 빈 은신처 1) 중 7장이 은신처 7곳에 숨고 3장은 치워집니다. 스네이크 순서로 한 사람이 두 번씩 턴을 가집니다.
3. 내 턴에는 단서 토큰이 0~1개인 **은신처 2곳을 몰래 엿보고**, 본 동물 중 하나의 **단서 토큰**을 아무 은신처에나 놓습니다(진짜든 가짜든). 토큰 2개가 놓인 은신처는 잠깁니다. 빈 은신처를 봤다면 아무 토큰이나 놓을 수 있습니다.
4. 모두 턴을 마치면 개인 추리판 7칸을 확정해 동시에 공개하고, 맞힌 은신처마다 1점. 누적 점수가 가장 높은 사람이 이깁니다.

해석은 [구현 규칙서](docs/hide-and-seek-rulebook.md)에, 엔진은 [engine.ts](backend/src/game-room/hide-and-seek/engine.ts)에 있습니다.
