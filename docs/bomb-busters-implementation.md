# 봄버스터즈 캠페인 구현 진행

전체 범위: 조사한 기본판 미션 1–66을 기존 NestJS/Socket.IO/React에 단계적으로 반영한다.

| 단계 | 범위 | 상태 |
| --- | --- | --- |
| 1 | 미션 설정 분리, 훈련 1–8, 기본 장비 12종, 서버 미션 선택, 공개 정보 직렬화 | 완료: 백엔드 55개·프론트 21개·실제 소켓 38개 검증 |
| 2 | 반복 규칙 모듈과 비음성 미션, 추가 장비·개인 장비, 특수 행동 UI | 완료: 백엔드 105개·프론트 41개·실제 소켓 91개 검증 |
| 3 | 음성 19·30·42·54·66, 동기화된 시간 이벤트, 벙커 지도 | 완료: 백엔드 137개·프론트 47개·실제 소켓 96개 검증 |

규칙 근거: [66개 미션](bomb-busters-missions.md), [부속 구성물](bomb-busters-mission-components.md). 구현 여부는 실제 카탈로그와 검증 결과로 기록한다.

검증은 규칙별 결정적 상태 테스트, 플레이어별 정보 비공개 검사, 실제 소켓 플레이, 프론트 사용자 행동, 빌드 순으로 진행한다. 기존 토이배틀·노터치크라켄의 방 시작·복귀도 회귀 확인한다.

## 최종 검증과 실행

- 백엔드 TypeScript 빌드와 규칙·직렬화·서버 타이머 테스트 137개 통과.
- 프론트 테스트 47개와 프로덕션 빌드 통과.
- 실제 HTTP/Socket.IO 96개 시나리오 통과: 훈련·자유 연습 36개는 승리까지, 캠페인 58개는 준비·개인별 정보·재접속·대기실 복귀까지 확인했다. 나머지 2개는 기존 게임 시작·복귀다. 모든 캠페인을 실제 소켓으로 승리까지 자동 해결한 것은 아니다.
- 실제 Chromium 두 클라이언트로 미션 66 선택, 개인 장비·초기 단서, 음성 미션 시작과 벙커 지도까지 확인했다. 브라우저 런타임 오류 0개, 모바일 390px에서 페이지 가로 넘침 없음.
- `clash-of-soldiers` tmux 세션의 단일 창·두 pane에서 백엔드 3001, 프론트 3000을 실행한다. 최종 개발 서버 컴파일 상태도 정상이다.
- 배포는 기존 Railway/Vercel의 저장소 연동을 사용한다. 수동 배포 명령은 추가하지 않았다.

## 모바일 화면과 절단 효과 — 2026-09-21

- 남은 실수와 해체 수를 아이콘·숫자 두 지표로 압축했다. 검증 토큰은 화면 폭에 맞춰 모든 숫자를 한 줄에 표시하며, 완료된 숫자는 초록색과 체크로 구분한다. 모바일의 충분한 높이에서는 현황판을 스크롤 중에도 상단에 고정한다.
- 서버가 확정한 결과에 식별자를 부여해 성공·실패 효과를 한 번씩 재생한다. 실패 시 약 1.2초 동안 화면 가장자리가 붉어지고 남은 실수 감소량을 표시한다. 성공 시 새로 해체한 전선과 해체 수를 강조한다.
- 초기 진입·재접속·동일 상태 갱신에는 이전 효과를 재생하지 않는다. 동작 줄이기 설정에서는 흔들림과 확대를 제거하고 붉은 효과를 완화한다.
- 최종 백엔드 145개·프론트 59개 테스트와 프로덕션 빌드 통과. 실제 두 브라우저에서 성공·연속 실패·재접속을 확인했고 320px·390px·1440px에서 12개 토큰이 가로 넘침 없이 한 줄로 표시된다.

## 디지털 구현의 해석과 차이

- 음성 미션은 [공식 음원 분석](bomb-busters-audio-rules.md)의 기계적 지시를 한국어 안내·선택과 서버 시간으로 표현한다. 원본 MP3와 동시에 재생하거나 초 단위로 동기화하지 않는다. 54번은 명시된 순수 작업시간 600초를 기준으로 이벤트 간격을 정규화한다.
- 42번의 눈 감기는 일시적인 정보 숨김으로, 구호는 참가자 버튼으로 표현한다. 첫 마술 이후 숫자별 자동 집계를 감춰 비공개 복구값이 집계 차이로 노출되지 않게 한다. 이미 공개된 전선의 위치나 값에 대한 기억까지 지우지는 않는다. 칼 던지기로 치운 전선은 빈 자리로 표시하되 서버의 전체 전선·완료 계산에는 보존한다.
- 도전 2·7의 연속 행동은 서로 다른 사람 수가 아니라 연속 차례로 판정한다. 2~3인에서 같은 대원의 차례가 다시 돌아오는 경우도 포함한다.
- 훈련 3의 인쇄 카드는 장비 2·12만 제외한다. 이를 따라 장비 11도 추첨 대상이지만 1–10 전선만 있어 원래 잠금 조건을 달성할 수 없다. 비공식 스크립트의 추가 제외 규칙은 채택하지 않았다.
- 24·40번에서 같은 받침대에 한 값이 네 개 모두 있는 경우에는 실제 개수인 ×4를 표시한다. 실물의 ×1·×2·×3 토큰 밖에서 가능한 디지털 표시다.
- 실제 대화·몸짓은 자동 감지하지 않는다. 허용된 신호와 위반 신고를 화면에 제공하고, 해당 미션이 명시한 벌점만 적용한다.
